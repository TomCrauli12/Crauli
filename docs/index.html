Сервисы обработки данных и интеграции

Фоновая обработка, обмен событиями, поиск и аналитические хранилища между компонентами приложений.

Контекст

Компонентам приложений требовались обмен данными, фоновые задачи, кеширование, поиск и аналитическая обработка.

Моя роль

Проектирование потока данных, подключение хранилищ и очередей, диагностика полного цикла запроса.

Инженерные решения

  • RabbitMQ и Apache Kafka для фоновых задач и обмена событиями.
  • MongoDB, ClickHouse и Elasticsearch применялись по назначению данных и сценария.
